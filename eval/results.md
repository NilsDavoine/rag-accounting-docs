Answer accuracy covers every test question: the right value for single facts, both values flagged for conflicts, the ambiguity flagged for ambiguous dates, a refusal for questions without an answer. Every configuration uses the same answer stage; only retrieval changes. Latency = retrieval + answer, per question.
